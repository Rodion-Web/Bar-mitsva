# Сохранение RSVP на Google Диск

Сайт отправляет ответы в Google Apps Script. Скрипт записывает их в Google Sheets и после каждого ответа создаёт актуальную копию `Ответы RSVP.xlsx` на вашем Google Диске.

1. Создайте новую таблицу Google Sheets на нужном Google Диске.
2. Скопируйте ID таблицы из её адреса: это часть между `/d/` и `/edit`.
3. Откройте [script.google.com](https://script.google.com), создайте проект и вставьте содержимое файла `google-apps-script.js`.
4. В строке `SPREADSHEET_ID` вставьте ID своей таблицы.
5. Нажмите «Развернуть» → «Новое развертывание» → тип «Веб-приложение». Выберите «Выполнять от имени: я», доступ — «Все». Подтвердите разрешения Google.
6. Скопируйте URL веб-приложения и вставьте его в `script.js` вместо пустой строки:

```js
const GOOGLE_APPS_SCRIPT_URL = "ВСТАВЬТЕ_СЮДА_URL";
```

После этого каждый ответ будет появляться на вкладке `RSVP` в таблице и обновлять файл `Ответы RSVP.xlsx` в корне того же Google Диска. Первый запуск может попросить разрешение на создание Excel-файла.
